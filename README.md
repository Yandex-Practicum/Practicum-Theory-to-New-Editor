# Practicum Theory to New Editor

Расширение для переноса контента из Yonote и Wiki в новый редактор теории Praktikum.

Что умеет:
- копировать контент со страниц `yonote.ru` и `wiki.yandex-team.ru`
- сохранять markdown и доступные картинки
- вставлять результат в страницу теории Praktikum

Для локальной проверки:

```bash
npm test
```

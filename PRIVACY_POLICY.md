Privacy Policy for Practicum Theory to New Editor

Effective date: March 4, 2026

Practicum Theory to New Editor is a browser extension designed to help authorized users transfer content from supported Yonote and Yandex Wiki pages into the Yandex Practicum theory editor.

1. Information We Process

The extension processes website content from supported pages only when the user actively uses the extension for its intended purpose. This may include page text, images, links, and related content required to copy, transform, and transfer material into the destination editor.

2. How Information Is Used

The processed content is used only to:

- read content from supported source pages
- prepare that content for transfer
- write the prepared result to the clipboard or insert it into the supported destination editor
- maintain temporary extension state required to complete the transfer workflow

3. Data Collection

The extension does not collect personally identifiable information for analytics, profiling, advertising, or resale.

The extension does not collect health data, financial data, authentication credentials, personal communications, or location data.

4. Data Storage

The extension may temporarily store workflow-related state in the browser's extension storage to support the transfer process. This storage is used only for functionality directly related to the extension's single purpose.

5. Data Sharing

The extension does not sell user data.

The extension does not use or transfer user data for advertising, profiling, or any purpose unrelated to the extension's single purpose.

The extension may access supported pages and related asset storage hosts only as technically necessary to complete the content transfer workflow initiated by the user.

6. User Control

The extension is user-initiated. It runs only when the user interacts with supported pages and uses the extension for content transfer.

7. Security

The extension limits processing to the minimum website content necessary to perform the requested transfer workflow.

8. Changes to This Policy

This privacy policy may be updated from time to time. Any updates will be reflected in this file with a revised effective date.

9. Contact

For questions about this privacy policy or the extension, contact the publisher through the support information provided in the Chrome Web Store listing.
